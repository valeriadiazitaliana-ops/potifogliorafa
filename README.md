# 🚀 Meu Portfólio Acadêmico

Bem-vindo ao repositório do meu portfólio acadêmico! Este projeto foi desenvolvido com o objetivo de centralizar e apresentar meus trabalhos, códigos e evolução na área de tecnologia.

## 🛠️ Tecnologias Utilizadas
O site foi construído do zero utilizando as tecnologias fundamentais da Web:
* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização moderna, design responsivo e tema escuro.
* **JavaScript (ES6+):** Lógica e interatividade dinâmica.

## 📂 Projetos em Destaque
* **Jogo da Memória (C# / Console):** Implementação de lógica estruturada em C# com matriz de 6x3 e validação de pares.
* **Pizzaria Italiana (Web):** Aplicação multipágina separando HTML, CSS e JavaScript para exibição de cardápio.
